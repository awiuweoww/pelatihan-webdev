LANGKAH 1: MENAMBAHKAN KOLOM HARGA KE DATABASE (MIGRATION)
--------------------------------------------------------------------------------
Jalankan perintah ini di terminal untuk membuat file migrasi baru:
> php artisan make:migration add_harga_to_peminjamans_table

Buka file migrasi baru yang baru saja digenerate di folder database/migrations/.
[PATH FILE: database/migrations/2026_10_19_000000_add_harga_to_peminjamans_table.php]
(Catatan: Sesuaikan nama file dengan timestamp yang digenerate sistem Anda)

KODE LENGKAP:
--------------------------------------------------------------------------------
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration
{
    /**
     * Menambahkan kolom harga satuan dan total harga transaksi.
     */
    public function up(): void
    {
        Schema::table('peminjaman', function (Blueprint $table) {
            $table->decimal('harga_satuan', 12, 2)->default(50000)->after('jumlah_pinjam');
            $table->decimal('total_harga', 12, 2)->default(50000)->after('harga_satuan');
        });
    }

    /**
     * Rollback penghapusan kolom.
     */
    public function down(): void
    {
        Schema::table('peminjaman', function (Blueprint $table) {
            $table->dropColumn(['harga_satuan', 'total_harga']);
        });
    }
};
--------------------------------------------------------------------------------

Setelah menyimpan kode di atas, jalankan perintah eksekusi migrasi di terminal:
> php artisan migrate

LANGKAH 2: UPDATE MODEL ELOQUENT (MASS ASSIGNMENT & CASTS)
--------------------------------------------------------------------------------
Buka file model Peminjaman untuk mendaftarkan kolom baru ke $fillable:
[PATH FILE: app/Models/Peminjaman.php]

KODE LENGKAP:
--------------------------------------------------------------------------------
<?php

namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Database\Eloquent\Model;

class Peminjaman extends Model
{
    use HasFactory;

    protected $table = 'peminjaman';

    // [KEAMANAN - PROTEKSI MASS ASSIGNMENT]:
    // Kolom harga_satuan dan total_harga didaftarkan ke $fillable agar aman dari manipulasi input
    protected $fillable = [
        'kode_transaksi',
        'nama_peminjam',
        'alat_dipinjam',
        'jumlah_pinjam',
        'harga_satuan',
        'total_harga',
        'tanggal_pinjam',
        'tenggat_kembali',
        'status',
    ];

    protected function casts(): array
    {
        return [
            'jumlah_pinjam' => 'integer',
            'harga_satuan'  => 'decimal:2',
            'total_harga'   => 'decimal:2',
            'tanggal_pinjam' => 'date',
            'tenggat_kembali' => 'date',
        ];
    }
}

LANGKAH 3: MENENTUKAN HARGA PER ALAT & LOGIKA HITUNG DI CONTROLLER
--------------------------------------------------------------------------------
Buka file controller peminjaman:
[PATH FILE: app/Http/Controllers/PeminjamanController.php]

Lakukan 2 penyesuaian:
1. Di method getMasterAlat(), tambahkan atribut 'harga' pada tiap barang:
--------------------------------------------------------------------------------
    private function getMasterAlat(): array
    {
        return [
            ['nama' => 'Tenda Dome 4P',    'total' => 10, 'harga' => 60000],
            ['nama' => 'Carrier 60L',      'total' => 10, 'harga' => 45000],
            ['nama' => 'Kompor & Nesting', 'total' => 10, 'harga' => 25000],
            ['nama' => 'Sleeping Bag',     'total' => 10, 'harga' => 20000],
            ['nama' => 'Trekking Pole',    'total' => 10, 'harga' => 15000],
        ];
    }
--------------------------------------------------------------------------------

2. Di method store(), hitung harga (Jumlah Pinjam x Harga Satuan) sebelum disimpan ke database:
--------------------------------------------------------------------------------
    public function store(PeminjamanRequest $request)
    {
        $alat = $request->alat_dipinjam;
        $qty  = (int) $request->jumlah_pinjam;

        // [LOGIKA HARGA]: Ambil tarif sewa per alat lalu kalikan dengan kuantitas
        $hargaMap    = array_column($this->getMasterAlat(), 'harga', 'nama');
        $hargaSatuan = $hargaMap[$alat] ?? 50000;
        $totalHarga  = $qty * $hargaSatuan;

        $masterList = array_column($this->getMasterAlat(), 'total', 'nama');
        if (isset($masterList[$alat])) {
            $currentDipinjam = (int) Peminjaman::where('alat_dipinjam', $alat)
                ->where('status', 'Dipinjam')
                ->sum('jumlah_pinjam');

            $sisaStok = max(0, $masterList[$alat] - $currentDipinjam);

            if ($request->status === 'Dipinjam' && ($currentDipinjam + $qty) > $masterList[$alat]) {
                return back()
                    ->withInput()
                    ->with('error', "Stok tidak mencukupi! Sisa stok untuk alat \"{$alat}\" hanya tersisa {$sisaStok} unit (Anda meminta {$qty} unit).");
            }
        }

        $kode = $request->filled('kode_transaksi') ? $request->kode_transaksi : null;
        if (!$kode) {
            $last = Peminjaman::latest('id')->first();
            $nextNum = $last ? ($last->id + 1) : 1;
            $kode = 'TRX-' . str_pad($nextNum, 3, '0', STR_PAD_LEFT);
        }

        // [KEAMANAN - SQL INJECTION & MASS ASSIGNMENT]:
        // Simpan transaksi BESERTA harga satuan dan total harga ke database
        Peminjaman::create([
            'kode_transaksi'  => $kode,
            'nama_peminjam'   => $request->nama_peminjam,
            'alat_dipinjam'   => $request->alat_dipinjam,
            'jumlah_pinjam'   => $qty,
            'harga_satuan'    => $hargaSatuan,
            'total_harga'     => $totalHarga,
            'tanggal_pinjam'  => $request->tanggal_pinjam,
            'tenggat_kembali' => $request->tenggat_kembali,
            'status'          => $request->status ?? 'Dipinjam',
        ]);

        return to_route('peminjaman.index')->with('success', 'Data transaksi peminjaman berhasil ditambahkan!');
    }

LANGKAH 4: MEMBUAT CONTROLLER KHUSUS DAFTAR TRANSAKSI
--------------------------------------------------------------------------------
Jalankan perintah ini di terminal untuk membuat TransaksiController:
> php artisan make:controller TransaksiController

Buka file controller yang baru dibuat:
[PATH FILE: app/Http/Controllers/TransaksiController.php]

KODE LENGKAP:
--------------------------------------------------------------------------------
<?php

namespace App\Http\Controllers;

use App\Models\Peminjaman;
use Illuminate\Http\Request;

class TransaksiController extends Controller
{
    /**
     * Menampilkan daftar transaksi peminjaman lengkap dengan total harga.
     * Kolom: Nama Peminjam, Barang Dipinjam, Total Barang, Total Harga.
     */
    public function index()
    {
        // [KEAMANAN - SQL INJECTION]: Eloquent latest() dan paginate() menggunakan prepared statements
        $transaksis = Peminjaman::latest()->paginate(10);

        // Menghitung akumulasi statistik ringkasan transaksi
        $totalPendapatan = Peminjaman::sum('total_harga');
        $totalTransaksi  = Peminjaman::count();
        $totalUnitSewa   = Peminjaman::sum('jumlah_pinjam');

        return view('transaksi.index', compact('transaksis', 'totalPendapatan', 'totalTransaksi', 'totalUnitSewa'));
    }
}

LANGKAH 7: PENGUJIAN DAN VERIFIKASI
--------------------------------------------------------------------------------
1. Cek apakah rute baru sudah terdaftar:
   > php artisan route:list --name=transaksi

2. Jalankan development server (jika belum berjalan):
   > php artisan serve

3. Buka browser pada URL:
   http://127.0.0.1:8000/transaksi
   atau klik menu baru "Daftar Transaksi" di sidebar sebelah kiri.

4. Verifikasi isi tabel:
   - Kolom "Nama Peminjam" tampil sesuai nama pelanggan.
   - Kolom "Barang Dipinjam" menampilkan nama alat gunung.
   - Kolom "Total Barang" menampilkan kuantitas (jumlah unit).
   - Kolom "Total Harga" menampilkan format nominal rupiah (Rp).
